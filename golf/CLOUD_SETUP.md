# クラウド同期の設定手順

Googleログインでデータをクラウドに保存し、機種変更や複数端末で同じデータを使えるようにします。
兄弟で使っても、**お互いのデータは見えません**（アカウントごとに完全に分かれます）。

無料の範囲で収まります（Firebase Sparkプラン。1日あたりの読み書き上限は5万回で、
この使い方だと1人1日あたり数十回程度です）。

作業はパソコンの方がやりやすいですが、スマホでもできます。**所要10〜15分**。

---

## 手順1：Firebaseプロジェクトを作る

1. `https://console.firebase.google.com/` を開く（普段のGoogleアカウントでログイン）
2. **「プロジェクトを作成」**（または「Firebase プロジェクトを作成」）をタップ
3. プロジェクト名に **`trd-golf`** と入力 → 続行
4. 「Google アナリティクス」は **オフ** にして続行（不要です）
5. 「プロジェクトを作成」→ 完了するまで30秒ほど待つ

## 手順2：ウェブアプリを登録する

1. プロジェクトのトップ画面で、**`</>`（ウェブ）のアイコン**をタップ
2. アプリのニックネームに **`TRD GOLF`** と入力
3. 「Firebase Hosting も設定する」は **チェックを入れない**
4. **「アプリを登録」** をタップ
5. 次の画面に、こういう文字列が出ます。**この `{ }` の中身をまるごとコピー**してください

```js
const firebaseConfig = {
  apiKey: "AIza............",
  authDomain: "trd-golf.firebaseapp.com",
  projectId: "trd-golf",
  storageBucket: "trd-golf.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
```

> この値は秘密情報ではありません。公開されても問題ないよう設計されています。
> データの保護は手順5のルールで行います。

## 手順3：Googleログインを有効にする

1. 左メニューの **「構築」→「Authentication」** をタップ
2. **「始める」** をタップ
3. 「ログイン方法」の一覧から **「Google」** をタップ
4. 右上の **「有効にする」** をオンにする
5. 「プロジェクトの公開名」はそのまま、「プロジェクトのサポートメール」に自分のGmailを選ぶ
6. **「保存」**

## 手順4：アプリのURLを許可する

1. Authentication の **「設定」タブ** → **「承認済みドメイン」**
2. **「ドメインを追加」** をタップ
3. **`trd00.github.io`** と入力して追加

> これをしないと、ログイン時に「このドメインは承認されていません」と出ます。

## 手順5：データベースを作り、保護ルールを入れる

1. 左メニューの **「構築」→「Firestore Database」**
2. **「データベースの作成」** をタップ
3. ロケーションは **`asia-northeast1`（東京）** を選ぶ
4. 「本番環境モードで開始」を選んで作成
5. できたら **「ルール」タブ** を開き、書いてある内容を**全部消して**、
   このリポジトリの `golf/firestore.rules` の中身をそのまま貼り付ける
6. **「公開」** をタップ

## 手順6：アプリに設定を貼り付ける

1. アプリ（`https://trd00.github.io/eigyoukikaku/golf/`）を開く
2. **分析タブ** → 下の方の **「クラウド同期（Googleログイン）」**
3. **「クラウド設定を貼り付ける」** を開く
4. 手順2でコピーした内容を貼り付けて **「保存して接続」**
5. **「Googleでログイン」** をタップ → 自分のGoogleアカウントを選ぶ

「状態：同期済み」と出たら完了です。

## もう1台の端末で使うとき

同じURLを開き、手順6と同じように設定を貼り付けて、**同じGoogleアカウント**でログインします。
既に入っているデータとクラウドのデータは**統合**されます（どちらかが消えることはありません）。

## お兄さんが使うとき

同じURLを開き、最初の画面で **「別の人が使う」** を選びます。
クラウドを使う場合は、同じ設定を貼り付けたうえで **お兄さん自身のGoogleアカウント** でログインしてください。
アカウントが違えばデータは完全に分かれます。

---

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 「このドメインは承認されていません」 | 手順4が未完了。`trd00.github.io` を承認済みドメインに追加する |
| 「状態：接続できません」 | 通信が届いていない。電波のある場所で開き直す。それでも出るなら設定の貼り付け内容を確認する |
| ログイン画面が出ずに戻ってくる | ホーム画面から起動した場合に起こることがある。Safariで開いてログインすると、以後はホーム画面からも同期される |
| 「権限がありません」と出る | 手順5のルールが未公開。ルールタブで「公開」を押したか確認する |
| データが二重に見える | 統合の仕様上、同じ内容を別々に登録するとどちらも残る。スコア一覧から不要な方を削除する |

## データを消したいとき

- **クラウドだけ消す**：分析タブ →「クラウド上のデータを削除」
- **この端末だけ消す**：分析タブ →「この端末の入力データを消去する」
- **アカウントごと消す**：Firebaseコンソール → Authentication → ユーザーを削除
