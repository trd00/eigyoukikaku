# 営業報告システム 操作マニュアル

スマホからサクッと営業報告を入力し、実績を自動集計・可視化するシステムです。
**Google スプレッドシート**をデータベースに、**Google Apps Script（GAS）**で動く Web アプリとして作られています。

---

## 1. まず全体像をつかむ

```
[営業担当者] --スマホ/PCで入力--> [報告フォーム(index.html)]
                                         |
                                         v
                             [GAS(コード.gs) saveReport]
                                         |
                                         v
                          [Google スプレッドシート(各シート)]
                                         |
                                         v
                             [GAS(コード.gs) getDashboardData]
                                         |
                                         v
[責任者/本人] <--集計を見る-- [実績ボード(dashboard.html)]
```

- 入力も閲覧も **Web ブラウザの URL を開くだけ**。アプリのインストールは不要です。
- データは全部 **1 つのスプレッドシート**の中に貯まります。
- **画面（HTML）はスプレッドシートには触りません。** 保存・集計はすべて `コード.gs` が行います。

### ファイルの役割

| ファイル | 役割 |
|---|---|
| `コード.gs` | バックエンド。画面表示・データ保存・集計を担当 |
| `index.html` | 営業担当者が入力する**報告フォーム** |
| `dashboard.html` | 実績を見る**ダッシュボード（実績ボード）** |

---

## 2. 【最重要】必要なシートを用意する

このシステムは、スプレッドシート内に**決まった名前のシート**があることを前提に動きます。
**シート名が 1 文字でも違うとエラー**になります（例：「報告データ」シートが見つかりません）。

まず、以下のシートを作ってください。

| シート名 | 役割 | 誰が用意する |
|---|---|---|
| `報告データ` | 全報告が貯まるマスター。**集計はここだけを見る** | 必須 |
| `受注` | 「受注」報告の振り分け先（見た目用の控え） | 必須 |
| `見積後日フォロー` | 「見積後日フォロー」報告の振り分け先 | 必須 |
| `受注なし` | 「受注なし」報告の振り分け先 | 必須 |
| `名簿` | 営業所と担当者の一覧（フォームのプルダウンの元） | 必須 |
| `キャンペーン一覧` | キャンペーン名の一覧 | 任意（無くても動く） |
| `目標管理` | 月ごとの目標値（ボードの達成率表示に使う） | 任意（無くても動く） |

### 2-1. `報告データ` ほか報告系シートの列の並び

`報告データ`・`受注`・`見積後日フォロー`・`受注なし` は**すべて同じ列構成**です。
1 行目にヘッダーを入れ、下の順番で列を並べてください（コードがこの順番でデータを書き込みます）。

| 列 | 項目 | 内容 |
|---|---|---|
| A | 登録日時 | 送信した日時（自動） |
| B | 報告種類 | 受注 / 見積後日フォロー / 受注なし |
| C | 機会種別 | キャンペーン / 同行販売 / 展示会 |
| D | 活動日 | 実際に営業した日 |
| E | メーカー | 任意入力 |
| F | 営業所 | |
| G | 担当者 | |
| H | お客様名 | |
| I | 商品名 | 受注なしの場合は空欄 |
| J | 品番 | 受注なしの場合は空欄 |
| K | 数量 | 受注なしの場合は空欄。**集計の「販売台数」はこの列を合計** |
| L | 単価 | |
| M | 金額 | 数量 × 単価（自動計算） |
| N | 不成約理由 | 受注なしの場合のみ入る |
| O | キャンペーン名 | 機会種別が「キャンペーン」のとき |

> 商品明細を複数入力すると、その**商品の数だけ行が増えます**（1 報告 = 複数行になることがあります）。

### 2-2. `名簿` シート

フォームの「営業所」「担当者」プルダウンは、このシートから作られます。

| 列 | 項目 |
|---|---|
| A | 営業所名 |
| B | 担当者名 |

- 1 行目はヘッダー（例：`営業所` / `担当者`）。
- 同じ営業所に担当者が複数いる場合は、**営業所名を繰り返して行を分けて**書きます。

```
営業所   担当者
本社     山田太郎
本社     鈴木花子
玖珂     佐藤一郎
```

- フォームでの営業所の表示順は `index.html` 内で
  `本社 → 玖珂 → 防府 → 大野 → 周南 → 山口 → 宇部 → 柳井 → 下関` と決められています。
  それ以外の営業所は後ろに続けて表示されます。

### 2-3. `キャンペーン一覧` シート（任意）

- A 列にキャンペーン名を 1 行ずつ書くだけ。
- 機会種別で「キャンペーン」を選んだときのプルダウンに出ます。
- 無い場合、キャンペーン名は空欄のまま登録されます。

### 2-4. `目標管理` シート（任意）

実績ボードの「目標」「達成率」表示に使います。

| 列 | 項目 | 例 |
|---|---|---|
| A | 年月 | `2026-07` または `2026年7月`（日付セルでも可） |
| B | 販売目標（台数） | `100` |
| C | アプローチ目標（件数） | `200` |

- 今月の行が無ければ、ボードには「目標未設定」と表示されます。

## 3. デプロイ（初回セットアップ）

1. 対象のスプレッドシートを開き、**拡張機能 → Apps Script** を開く。
2. スクリプトエディタに `コード.gs` の内容を貼り付ける。
3. 左の「ファイル」で HTML ファイルを 2 つ追加し、名前を **`index`** と **`dashboard`** にする
   （`.html` は付けない）。それぞれに `index.html` / `dashboard.html` の中身を貼り付け。
4. 右上の **デプロイ → 新しいデプロイ → 種類「ウェブアプリ」** を選ぶ。
   - 「次のユーザーとして実行」：**自分**
   - 「アクセスできるユーザー」：運用に合わせて選択（社内のみ等）
5. 発行された**ウェブアプリ URL** が、そのまま**報告フォーム**の URL です。
6. **実績ボード**を開くときは、その URL の末尾に **`?page=dashboard`** を付けます。

```
報告フォーム :  https://script.google.com/.../exec
実績ボード   :  https://script.google.com/.../exec?page=dashboard
```

> コードを直すたびに、**デプロイを更新**しないと URL 側に反映されません
> （デプロイ → デプロイを管理 → 編集 → バージョン「新バージョン」）。

## 4. 報告フォームの使い方（営業担当者向け）

1. **報告種類**を選ぶ：🟧受注 / 🟦見積後日フォロー / 🟩受注なし
   - 選ぶと画面の色が変わります。**「受注なし」を選ぶと商品明細が消え、不成約理由の入力欄**に変わります。
2. **機会種別**を選ぶ：🎯キャンペーン / 🤝同行販売 / 🏢展示会
   - 「キャンペーン」を選ぶとキャンペーン名の選択欄が出ます（必須）。
3. **基本情報**を入力：日時・メーカー（任意）・営業所・担当者・お客様名。
   - **担当者は、営業所を先に選ぶと選べるように**なります。
4. **商品明細**を入力：品番・商品名・数量・単価。金額は自動計算。
   - 「＋ 行を追加」で複数商品を入力できます。
   - 「受注なし」のときは代わりに**不成約理由**を選択（「その他」は自由記述）。
5. **「送信して集計シートに記録」**を押す。
6. 送信後、「続けて入力しますか？」と聞かれます。
   - **はい**＝お客様名を残して次を入力（同じ客先で続けて登録するとき便利）
   - **いいえ**＝お客様名もクリア

> 入力欄で Enter を押しても誤送信しないようになっています（送信はボタンのみ）。

---

## 5. 実績ボードの見方（責任者・本人向け）

- **今月分**（活動日=D 列が今月）のデータだけを自動集計します。
- 上部 KPI：総販売実績（台）／アプローチ件数／受注件数／成約率。
- **アプローチ件数**＝「日付＋お客様名＋担当者」で重複を除いた**訪問のユニーク数**。
- **受注件数**＝そのうち「受注」だった訪問のユニーク数。**成約率＝受注件数 ÷ アプローチ件数**。
- 営業所ランキング：行をタップすると担当者別の内訳が見られます。
- 売れ筋商品 TOP5・イベント種別の実績も表示。
- 右上の **🔄更新**で最新データを再取得します。

---

## 6. よくあるエラーと対処

| 症状 | 原因・対処 |
|---|---|
| 「〇〇シートが見つかりません」 | シート名が違う／未作成。**セクション 2 の名前と完全一致**させる |
| 担当者プルダウンが空 | `名簿` シートが空、または営業所を先に選んでいない |
| ボードが「読込中...」のまま | デプロイ未更新、または `報告データ` シートが無い。🔄更新も試す |
| 目標が「目標未設定」 | `目標管理` に**今月の行**が無い。年月の書式（`2026-07` 等）を確認 |
| 「処理が混み合っています」 | 同時送信の一時的な競合。少し待って再送信 |

---

## 7. 用語まとめ

- **KPI**：画面上部に出る重要指標（販売台数・アプローチ・受注・成約率）。
- **アプローチ**：客先への訪問 1 回を 1 件と数えたもの（同日同客先同担当は 1 件）。
- **機会種別／イベント**：その営業がどの場面（キャンペーン・同行・展示会）で発生したか。
