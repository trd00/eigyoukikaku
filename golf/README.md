# TRD GOLF PROJECT

「80台前半を、特別ではなく日常へ。」  
寺戸康晴（てらちゃん）専用のゴルフ育成・スコア管理アプリ（MVP v1.0）。

iPhone SafariからログインなしでURLを開くだけで使える、モバイルファーストのWebアプリ（PWA）です。
入力データはその端末のブラウザ（localStorage）だけに保存され、サーバーへは送信しません。

## 使い方（iPhone）

1. Safariで公開URLを開く
2. 共有ボタン → **ホーム画面に追加** → アプリのように全画面で起動できます
3. 下部ナビ（ホーム／記録／練習／スコア／分析）で画面を切り替えます

## 画面

| 画面 | できること |
|---|---|
| ホーム | PROJECT DAY・実施日・未実施日・達成率、今日のメニューとチェック、今日のステータス登録、相談、次のラウンド、今週の重点 |
| 記録 | 月間カレンダー（◎完了／△一部／休休養／×未実施・メモのある日は点で表示）、最近のメモ一覧、過去日の修正、開始日と目標スコアの変更 |
| 練習 | 打ちっぱなしの7I・ドライバー・仮想グリーンの記録、日曜の80球メニュー、番手別キャリー表 |
| スコア | 次のラウンドの予約と事前分析、ラウンド登録（カード形式の一覧）、詳細指標の入力、編集・削除、ゴルフ場（コースレート）管理 |
| 分析 | コースレート基準の現在地、診断、気になるポイント、練習プランの変更案、次に取りたいデータ、ゴルフ場別成績、推移グラフ、JSONバックアップ |

## 分析の考え方

直近5ラウンドとコースレートを基準に、**事実 → そこから言えること → 改善点** の順で組み立てます。
励ましも叱責も入れず、判別できないことは「判別できない」と書き、確定させるための計測項目を提示します。

- **ディファレンシャル** ＝（スコア − コースレート）× 113 ÷ スロープ  
  コース難易度を補正した数値。難しいコースの92と易しいコースの92を同じ土俵で比較できます。
- **推定ハンディキャップ**：ディファレンシャルの良い方から、ラウンド数に応じた本数を平均した参考値
- **想定スコア**：コースレート ＋ 推定ハンディ × スロープ ÷ 113。予約したコースの当日の目安になります
- **ゴルフ場別成績**：コースごとの平均・ベスト・ディファレンシャル平均・ミスの内訳
- **練習プランの変更案**：診断結果に対応する曜日メニューの差し替え案。「適用」するとホームの今日のメニューに反映されます
- **次に取りたいデータ**：診断で切り分けられなかった点（例：3パットが距離感由来か外し由来か）を確定させるための計測項目。取り方と目的つき

> コースレートは初期状態では**未登録**です（画面上に「CR未登録」と表示されます）。
> 推測値を入れると補正が狂うため空にしてあります。スコアカードの値を登録すると、
> ディファレンシャルと推定ハンディが計算されるようになります。

## メモへの応答

メモを保存すると、書いた内容に対する短いコメントと、次の練習日が表示されます。
外部のAIには接続しておらず、書かれた語（軌道・ボール位置・距離感・パット・疲労・痛みなど）と
その日の記録から返します。評価や励ましは入れず、「その気づきを次にどう確かめるか」だけを書きます。

痛みが記録された日は、他より優先して練習量を落とす案内を出します。
保存したメモは **記録タブの「最近のメモ」** から見返せます（カレンダーの日付をタップしても開けます）。

## 相談画面

ホームの「相談をひらく」から、会話形式で質問できます。**外部のAIには接続していません。**
登録された記録から計算した事実を返し、記録が無いことは「無い」と答えます。

- 質問は選択式（今日は何をすればいい／最近の調子は／何から直すべき／パット数が多いのは悪いこと／など）
- 「この内容をコピー」で、成績の要約を文章にしてクリップボードへコピーします。
  ChatGPTなどに貼り付ければ、そのまま相談を続けられます

### アドバイスの表示切り替え

利用者ごとに、診断とアドバイスを表示するかどうかを選べます（初期設定の5ステップ目、または分析タブ）。
オフにすると、診断・気になるポイント・練習プランの変更案・次に取りたいデータを表示せず、
スコアと練習の数値・グラフ・ゴルフ場別成績だけになります。相談画面は自分から開いたときだけ使えます。

## 計算ルール

- 経過日数 ＝ 今日 − 開始日 ＋ 1（開始日当日が PROJECT DAY 001）
- 実施日 ＝「完了」または「一部だけ実施」の日（同一日は重複カウントしない）
- 未実施日 ＝ 開始日〜昨日のうち、月曜（完全休養）以外で記録がない日、または「できなかった」を選んだ日
- 達成率 ＝ 実施日 ÷（実施日 ＋ 未実施日）× 100（休養日は分母に入れない／四捨五入）
- パーオン率 ＝ パーオン数 ÷ 18 × 100、ボギーオン率 ＝ ボギーオン以内の数 ÷ 18 × 100
- パーオン後3パット率 ＝ パーオン後3パット数 ÷ パーオン数 × 100（パーオン0なら表示なし）
- 日付はすべて日本時間（Asia/Tokyo）基準

## データについて

- **アプリはラウンド履歴を一切持ちません。**公開URLに個人のスコアを置くと、URLを知っている人全員が見られるためです。各利用者が自分で入力するか、バックアップ（JSON）から復元します
- 過去の記録は、初期設定画面か分析画面の「JSONを読み込む」から取り込めます。取り込みは**置き換えではなく統合**で、手元の入力は消えません
- ゴルフ場の一覧（名称のみ・スコアなし）は初期値として入っています。コースレートは未登録で、登録するとディファレンシャル（難易度補正）と推定ハンディが計算されます
- パーオン数・ボギーオン数・3パット数などは、記録がなければ**未入力（null）**として扱い、0回とは区別します。未入力の項目を根拠にした指摘は出しません
- 9ホールのラウンドは平均・ベスト・推移グラフから除外し、一覧には「9H」として残します
- 練習・キャリー・スコアは、その端末のlocalStorageだけに保存されます
- 別の端末・別のブラウザには自分の入力データは表示されません
- 履歴削除や機種変更で消えるため、分析画面の **JSONを書き出す** で定期的にバックアップしてください
- 楽天GORA由来のFWキープ率とOB数は未入力の可能性があるため、ペナルティは参考値として扱っています

## 開発

依存ライブラリなし。素のHTML／CSS／ES Modulesのみ。

```
golf/
├── index.html              画面（5ビュー＋下部ナビ＋ボトムシート）
├── css/style.css
├── js/
│   ├── app.js              画面制御（DOM操作のみ）
│   ├── stats.js            集計ロジック（純関数・UIから分離）
│   ├── diagnose.js         診断エンジン（コースレート補正・改善点・計測依頼）
│   ├── courses.js          ゴルフ場マスタ
│   ├── date.js             JST基準の日付計算
│   ├── menu.js             週間メニュー定義（既定＝てらちゃん用）
│   ├── plan.js             利用者ごとの週間メニュー生成
│   ├── consult.js          相談画面の回答とAI用の文章組み立て
│   ├── feedback.js         メモ保存時の応答・連続実施日数
│   ├── cloud.js            Googleログイン／クラウド保存
│   ├── merge.js            端末間データの統合
│   ├── seed.js             番手一覧（ラウンド履歴は持たない）
│   ├── store.js            localStorage永続化（SSR安全）
│   └── chart.js            SVG折れ線・散布図（外部ライブラリ不使用）
├── manifest.webmanifest    PWA
├── sw.js                   オフライン起動用Service Worker
├── firestore.rules         クラウドの保護ルール
├── CLOUD_SETUP.md          クラウド同期の設定手順
└── test/                   集計・統合・メニュー生成のテスト
```

ローカル確認：

```bash
cd golf && python3 -m http.server 8123   # http://127.0.0.1:8123/
```

テスト：

```bash
node --test golf/test/*.mjs
```

## 公開（GitHub Pages）

1. GitHubリポジトリの **Settings → Pages** を開く
2. Source を **Deploy from a branch**、Branch を `main` / `(root)` に設定して保存
3. 数分後、`https://<ユーザー名>.github.io/eigyoukikaku/golf/` で公開されます

ログイン不要の公開URLになるため、iPhone Safari・ChatGPT内ブラウザ・ホーム画面のいずれからでも同じURLで起動できます。

## クラウド同期と複数人での利用

- 初回起動時に、利用者ごとの初期設定を行います（名前 → 目標スコア → 練習できる曜日と時間 → 課題 → アドバイスの要否 → 確認）。
  回答から週間メニューを組み立て、選ばなかった曜日は休養日として達成率の分母から外します。設定は分析タブからやり直せます
- 誰が開いても空の状態から始まります。他人の記録は表示されません
- Googleログインを設定すると、機種変更や2台目の端末でも同じデータを使えます。設定手順は `CLOUD_SETUP.md`
- アカウントが違えばデータは完全に分かれます（保護ルールは `firestore.rules`）
- 2台で別々に編集した場合、項目ごとに新しい方を採用して統合します。片方の入力が丸ごと消えることはありません
- クラウド未設定でも、これまで通り端末内保存だけで動きます

## 初版の対象外

18ホールの一打単位入力、AIスイング解析、ランキング・SNS共有。
