# まえば小児科 WEB問診システム（試作版）

要件定義書にもとづく試作です。提案・院内デモ・院長先生との問診内容のすり合わせに使うことを想定しています。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `monshin.html` | 患者・保護者が入力する画面 |
| `monshin-admin.html` | 医院側の問診確認画面 |
| `monshin-schema.js` | **質問項目の定義**（ここを直せば質問を変更できる） |
| `monshin-schema.html` | 上記をGAS用に `<script>` で囲んだもの（自動生成） |
| `monshin.gs` | サーバー側（Google Apps Script） |

`monshin-schema.js` が質問項目の正本です。編集したら、GAS用のファイルを作り直してください。

```
{ echo '<script>'; cat monshin-schema.js; echo '</script>'; } > monshin-schema.html
```

## すぐに動かして見せる（サーバー不要）

`monshin.html` をブラウザで開くだけで動きます。インストールも設定も不要です。

- 送信したデータはそのブラウザの中だけに保存されます
- 続けて `monshin-admin.html` を開くと、いま送信した問診が一覧に出ます
- 管理画面はデモ用のサンプル5件を最初から表示します

画面右上に「デモ表示」と出ている間は、この単体モードで動いています。

## 実際に運用する（Google Apps Script）

> **注意：営業報告システムとは別のGASプロジェクトに作ってください。**
> このリポジトリにある `コード.gs`（営業報告システム）にも `doGet` があるため、
> 同じプロジェクトに入れると画面の表示処理がぶつかります。
> 問診システムは、専用のスプレッドシートとApps Scriptプロジェクトを新しく作って設置します。

1. Googleスプレッドシートを1つ作る
2. 「拡張機能 → Apps Script」を開く
3. 次のファイルを作成して中身を貼り付ける
   - `monshin.gs`（スクリプト）
   - `monshin.html`（HTML）
   - `monshin-admin.html`（HTML）
   - `monshin-schema.html`（HTML）
4. `monshin.html` と `monshin-admin.html` の
   `<script src="monshin-schema.js"></script>` の行を
   `<?!= include('monshin-schema') ?>` に書き換える
5. エディタ上で `setupMonshinSheets` を1回実行する（シートが作られます）
6. 「デプロイ → 新しいデプロイ → ウェブアプリ」で公開する

公開後のURL

- 患者用：`https://.../exec`
- 医院用：`https://.../exec?page=admin`

患者用URLをQRコードにして、院内掲示・ホームページ・LINEに載せます。

### 公開範囲について

デプロイ時の「アクセスできるユーザー」は用途で分けてください。

- 患者用は「全員」にする必要があります
- 医院用（`?page=admin`）も同じURLのため、同じ公開範囲になります

**そのため、現状の作りでは管理画面もURLを知っていれば開けます。**
本番運用前に、以下のいずれかの対応が必要です（要検討事項）。

- 管理画面を別デプロイに分け、「Googleアカウントを持つ自分だけ / 組織内」に限定する
- 管理画面に暗証番号による確認を追加する

## 実装済みの機能

### 患者側

- 受診区分の選択（初診／再診／発熱・感染症／予防接種／健診）
- 患者基本情報の入力、生年月日からの年齢自動計算
- 回答内容に応じた質問の出し分け（条件分岐）
- 必須項目の未入力チェック
- 入力途中の一時保存（同じ端末・2時間以内）
- 送信前の内容確認画面
- 送信完了画面（受付・発熱時の待機・緊急時連絡の案内）
- 緊急性の高い回答に対する画面上の注意表示

### 医院側

- 問診一覧（緊急度の高い順に自動で並び替え）
- 本日件数・未確認・要確認・発熱ありの集計表示
- 氏名・ふりがな・診察券番号・電話番号での検索
- 受診区分・状態・要確認・発熱・未確認での絞り込み
- 詳細表示（緊急項目を赤く強調）
- ステータス管理（未確認／受付確認済み／看護師確認済み／医師確認済み／診察完了／キャンセル）
- 職種別の操作権限（受付・看護師・医師・管理者）
- 印刷、CSV出力

### サーバー側（GAS）

- スプレッドシートへの保存
- 送信内容のサーバー側チェック
- 操作履歴の記録
- 保存期間を過ぎたデータの削除（`purgeOldMonshin`、初期設定180日）

## 質問項目の直し方

`monshin-schema.js` を開くと、問診ごとに質問が並んでいます。
画面側のコードを触らずに、追加・削除・文言変更ができます。

```js
{ id: 'v_temp', type: 'temperature', required: true, label: '今の体温' },
```

| 書く項目 | 意味 |
|---|---|
| `id` | 回答を区別する名前。重複しないようにする |
| `type` | `radio` `checkbox` `select` `text` `textarea` `number` `date` `datetime-local` `temperature` |
| `label` | 患者に表示する質問文 |
| `help` | 補足説明 |
| `required` | `true` にすると必須 |
| `options` | 選択肢 |
| `showIf` | 表示条件 |
| `urgent` | 注意喚起の条件 |
| `summary` | `true` で医院側一覧の「主な症状」に出る |

### 例：ある回答のときだけ質問を出す

```js
{ id: 'v_antipyretic', type: 'radio', label: '解熱剤を使いましたか', options: YN },
{ id: 'v_antipyretic_time', type: 'datetime-local', label: '最後に使ったのはいつですか',
  showIf: { q: 'v_antipyretic', op: 'eq', v: 'あり' } },
```

### 例：注意喚起を出す

```js
urgent: { op: 'eq', v: 'ほとんど飲めない', level: 'critical',
          msg: '水分がとれていません。脱水の心配があります。' }
```

- `level: 'critical'` … 赤色。電話連絡・救急受診の案内も出る
- `level: 'high'` … 黄色。医院側の一覧で「要確認」になる

月齢による判定もできます。

```js
{ op: 'gte', v: 38, ageUnderMonths: 3, level: 'critical',
  msg: '生後3か月未満で38℃以上の発熱です。すぐにお電話ください。' }
```

## 現在の問診項目

| 問診 | セクション数 | 質問数 |
|---|---|---|
| 初診 | 5 | 28 |
| 再診 | 3 | 14 |
| 発熱・感染症 | 5 | 25 |
| 予防接種 | 4 | 22 |
| 健診 | 5 | 23 |

合計112問。すべてが一度に出るわけではなく、条件分岐により実際に表示されるのは各回20〜30問程度です。

## 注意喚起の条件について

**現在設定している条件は、要件定義書の項目をもとにした仮置きです。**
実際の運用前に、必ず院長先生に内容を確認していただく必要があります。

現在の設定：

| 条件 | 表示 |
|---|---|
| 生後3か月未満で38℃以上 | 赤（至急） |
| 40℃以上 | 黄 |
| 呼吸が苦しそう | 赤 |
| けいれんが継続している | 赤 |
| 水分がほとんど飲めない | 赤 |
| 半日以上排尿がない | 赤 |
| ぐったりしている | 赤 |
| 意識の反応が鈍い | 赤 |
| 顔色不良・チアノーゼ | 赤 |
| 感染症の接触歴あり | 黄 |
| アレルギーあり | 黄 |
| 予防接種前に37.5℃以上 | 黄 |

WEB問診だけで緊急度を確定させない方針とし、赤の場合は「電話連絡・救急受診」を案内する文面にしています。
